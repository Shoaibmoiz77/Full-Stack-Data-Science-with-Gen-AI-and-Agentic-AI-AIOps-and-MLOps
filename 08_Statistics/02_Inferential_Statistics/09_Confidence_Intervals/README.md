# Confidence Intervals

From a point estimate to a range of plausible values.

## What is inside

- [`01_Confidence_Intervals_Notes.pdf`](./01_Confidence_Intervals_Notes.pdf): in-depth notes with worked examples, charts, a Python snippet, a summary and practice questions with answers
- [`02_Confidence_Intervals_Class_Slides.pdf`](./02_Confidence_Intervals_Class_Slides.pdf): the 21 class slides in lecture order, one per page

## Topics covered

- Confidence level and α; correct interpretation
- z interval (σ known) using the class salary example
- t interval (σ unknown) and the t distribution
- Interval for a proportion; sample-size planning
- Difference of two means; which formula to use
