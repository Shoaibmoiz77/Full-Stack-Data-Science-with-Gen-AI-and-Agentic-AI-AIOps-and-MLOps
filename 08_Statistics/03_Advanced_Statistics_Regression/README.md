# Advanced Statistics: Regression Analysis

From correlation to multivariate regression, taught with the instructor's slides.

Study the folders in order. Each holds in-depth notes (PDF), the class slides as a PDF (in lecture order) and the original lecture text.

| # | Folder | What you learn |
|---|--------|----------------|
| 01 | [`01_Regression_Analysis_and_Correlation_vs_Causation`](./01_Regression_Analysis_and_Correlation_vs_Causation/) | Prediction with regression, and why correlation is not causation. |
| 02 | [`02_Correlation_vs_Regression`](./02_Correlation_vs_Regression/) | How the two ideas differ. |
| 03 | [`03_Graphical_Representation_of_Regression`](./03_Graphical_Representation_of_Regression/) | The regression line, its parts and a first example. |
| 04 | [`04_Sums_of_Squares_R_Squared_and_OLS`](./04_Sums_of_Squares_R_Squared_and_OLS/) | Splitting variability, measuring fit, and how the line is found. |
| 05 | [`05_Regression_Table`](./05_Regression_Table/) | Reading the output a statistics package gives you. |
| 06 | [`06_Multivariate_Linear_Regression`](./06_Multivariate_Linear_Regression/) | Regression with more than one independent variable. |
| 07 | [`07_Adjusted_R_Squared`](./07_Adjusted_R_Squared/) | R-squared that penalises useless variables. |
| 99 | [`99_Practice_Notebook`](./99_Practice_Notebook/) | A public statistics tutorial notebook and a dataset to practise on. |

## Learning path

```text
Regression idea -> Correlation vs regression -> The regression line
   -> Sums of squares, R-squared, OLS -> Regression table
   -> Multivariate regression -> Adjusted R-squared
```
