# Sums of Squares, R-squared and OLS

Splitting variability, measuring fit, and how the line is found.

## What is inside

## Topics covered

- SST, SSR and SSE; SST = SSR + SSE
- R-squared = SSR / SST and what counts as a good value
- Ordinary least squares (OLS) as minimising SSE
- Other methods: Bayesian, kernel and Gaussian-process regression
