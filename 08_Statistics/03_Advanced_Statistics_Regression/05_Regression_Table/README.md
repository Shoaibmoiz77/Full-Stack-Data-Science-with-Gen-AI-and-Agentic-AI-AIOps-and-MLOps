# Reading the Regression Table

Reading the output a statistics package gives you.

## What is inside

- [`01_Regression_Table_Notes.pdf`](./01_Regression_Table_Notes.pdf): in-depth notes with worked examples, charts, a Python snippet, a summary and practice questions with answers
- [`02_Regression_Table_Class_Slides.pdf`](./02_Regression_Table_Class_Slides.pdf): the 19 class slides in lecture order, one per page
- [`class_material/`](./class_material/): the instructor's lecture text and `Regression-table.xlsx` (unedited)

## Topics covered

- Model summary: R-squared, sample size, standard error
- ANOVA table and the F-statistic
- Coefficient table: b0, b1, standard errors, t-statistics, p-values
- Testing H0: coefficient = 0
