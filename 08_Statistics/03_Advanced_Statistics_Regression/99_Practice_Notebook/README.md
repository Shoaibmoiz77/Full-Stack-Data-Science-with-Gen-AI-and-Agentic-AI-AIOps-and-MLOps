# Practice Notebook

A hands-on statistics tutorial notebook with a dataset to practise on.

## What is inside

- [`stats_tutorial.ipynb`](./stats_tutorial.ipynb): the notebook (Python)
- [`stats_tutorial_printout.pdf`](./stats_tutorial_printout.pdf): a 32-page PDF print of the notebook's GitHub page, saved on 24 Feb 2024
- [`toy_dataset.csv`](./toy_dataset.csv): 150,000 rows with columns Number, City, Gender, Age, Income, Illness

## Topics covered

- Discrete and continuous variables; PMF, PDF, CDF
- Uniform, normal, binomial, Poisson and log-normal distributions
- Mean, median, mode and moments; bias, MSE and standard error
- Sampling methods, covariance and correlation
- Linear regression and Anscombe's quartet; bootstrapping
- Hypothesis testing, p-values, q-q plots, outliers
- Overfitting, cross validation, generalised linear models, frequentist vs Bayes
