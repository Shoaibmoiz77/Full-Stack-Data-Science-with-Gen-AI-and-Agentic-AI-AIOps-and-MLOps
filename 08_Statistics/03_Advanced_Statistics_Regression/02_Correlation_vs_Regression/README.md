# Correlation vs Regression

How the two ideas differ.

## What is inside

- [`01_Correlation_vs_Regression_Notes.pdf`](./01_Correlation_vs_Regression_Notes.pdf): in-depth notes with worked examples, charts, a Python snippet, a summary and practice questions with answers

- [`class_material/`](./class_material/): the instructor's lecture text (unedited)

## Topics covered

- Correlation measures the degree of relationship; regression models cause and effect
- Correlation is symmetric, regression is one-way
- How each is drawn: a single point vs the best-fitting line

The Excel file used in the lecture, `Correlation-and-causation.xlsx`, is the same file stored in the previous folder, so it is kept only there.
