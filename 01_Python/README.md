## 🎯 Learning Path

The topics are numbered in the order they were learned — starting from Python syntax basics, moving through data structures and control flow, and finishing with the core data science stack (NumPy → Pandas → Matplotlib → Seaborn). Each folder contains Jupyter notebooks with worked examples, and several include supplementary PDF notes or interview-prep material.
